# CARLV.SION — Portfolio

High-contrast, high-energy concert photography and video editing portfolio. Built with a focus on raw aesthetic and refined digital vision.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid)
- **Deployment:** Vercel
- **Forms:** Formspree AJAX API
- **Animations:** Intersection Observer API (Scroll Reveal)

## Project Structure
- `/index.html` - Landing page & Hero
- `/gallery.html` - Masonry photography showcase
- `/about.html` - Professional background & branding
- `/contact.html` - Client outreach form
- `/404.html` - Custom error fallback

## Local Development
To view the project locally, simply clone the repository and open `index.html` in any modern web browser.
